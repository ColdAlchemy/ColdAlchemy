# Uso de IA nos meus projetos

Os projetos de portfólio abaixo foram **desenvolvidos por mim com o auxílio do Claude Code** (um assistente de programação com IA). Eu defino o escopo, reviso o código gerado, rodo os testes e estudo cada parte; cada projeto traz um guia de estudo (`docs/ESTUDO.md`) com as perguntas que eu preciso saber responder sobre ele.

Os repositórios antigos feitos antes disso (`consultas-medicas-api` e `Atividade-Desv.Web`) foram feitos **sem IA**, e as cópias originais ficam preservadas nos repositórios com sufixo `-original`.

## O que isso não significa
- Os dados de demonstração são fictícios ou sintéticos, e cada README diz o que **não** foi feito (por exemplo, IA simulada na demonstração do DocsIA e API real testada só com HTTP simulado).
- Os históricos de commit trazem o rodapé `Co-Authored-By: Claude`, que é o registro automático dessa colaboração.
- Se alguém quiser saber mais, eu respondo com a verdade sobre o que fiz sozinho e o que foi com apoio.
